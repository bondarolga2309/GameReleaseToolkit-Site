# Game Release Toolkit Landing Page

Static landing page for the upcoming Game Release Toolkit desktop application.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public repository (for example `GameReleaseToolkit-Site`).
2. Upload `index.html` and `styles.css` to the repository root.
3. In GitHub, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The page intentionally labels the application as "Coming Soon" and the embedded product preview as a UI concept.
